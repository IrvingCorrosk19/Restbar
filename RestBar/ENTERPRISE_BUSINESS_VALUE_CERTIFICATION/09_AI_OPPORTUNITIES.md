# 09 — OPORTUNIDADES IA (Fase 13)

**¿Puede RestBar responder hoy con IA?** **NO** — no hay capa IA integrada verificada.

| Pregunta IA | ¿Hoy? | Prerrequisitos |
|-------------|-------|----------------|
| ¿Qué debo hacer hoy? | ❌ | Dashboard ejecutivo + alertas |
| ¿Qué comprar/vender/promocionar? | ❌ | PO + promo engine + forecast |
| ¿Dónde pierdo dinero? | ⚠️ | Rentabilidad producto; sin prime cost |
| ¿Sucursal requiere atención? | ⚠️ | Comparación branch manual |
| ¿Empleado necesita capacitación? | ❌ | KPI por empleado incompleto |
| ¿Productos eliminar/agregar? | ⚠️ | Menu engineering data |
| ¿Clientes recuperar? | ❌ | CRM + churn model |
| ¿Riesgos/oportunidades semana? | ❌ | Event stream + rules |
| ¿Decisiones gerente? | ❌ | Copiloto requiere datos completos |

**Oportunidad:** RestBar tiene **datos operativos ricos** (órdenes, KDS, pagos, multitenant) — base sólida para **copiloto gerencial** en fase 2 post-compras+caja.

**Prioridad IA (post-fundamentos):**
1. Alertas reglas (sin ML): stock bajo, sucursal bajo ventas, estación lenta
2. Recomendaciones menu (quitar/promocionar) desde rentabilidad
3. NLP queries sobre reportes ("¿ventas ayer Norte?")
4. Forecast demanda ML

**Score innovación IA actual: 5/100** (potencial futuro: 65/100 con roadmap)
