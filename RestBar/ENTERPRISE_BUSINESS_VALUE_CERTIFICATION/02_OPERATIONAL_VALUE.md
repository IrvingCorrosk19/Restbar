# FASE 3 — ¿AYUDA A GANAR MÁS DINERO?

| Palanca | Estado | Qué falta |
|---------|--------|-----------|
| Ticket promedio | ❌ | Upselling, combos (SB-09), sugerencias POS |
| Ventas por mesa/hora/sucursal/empresa | ⚠️ | Reportes históricos; no tiempo real ejecutivo |
| Rotación mesas | ⚠️ | KDS acelera indirectamente; sin precuenta |
| Velocidad servicio | ✅/⚠️ | KDS certificado; caja lenta sin precuenta |
| Recompra / fidelización | ❌ | Sin CRM, loyalty, VIP estructurado |
| Upselling / cross-selling | ❌ | No implementado |
| Combos | ❌ | SB-09 |
| Promociones / Happy Hour | ❌ | SB-10; precio manual único |
| Temporada / eventos | ❌ | Sin motor promocional |

**Conclusión Fase 3:** RestBar **no está diseñado hoy para crecer ingresos activamente**. Ayuda **indirectamente** vía velocidad cocina. Para crecimiento activo faltan combos, HH, loyalty, upsell.
