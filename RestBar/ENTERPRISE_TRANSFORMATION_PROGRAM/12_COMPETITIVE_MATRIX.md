# 4. Capacidades mínimas para “competir” (no para “ser Toast”)

**Must (12 meses):** Caja, precuenta, PO, food cost, promo/combo, export, fiscal piloto, Command Center v1  
**Should (18 meses):** Forecast, loyalty, SaaS billing, alerts  
**Differentiator (24 meses):** Copilot ES, franchise pack, multiempresa analytics
