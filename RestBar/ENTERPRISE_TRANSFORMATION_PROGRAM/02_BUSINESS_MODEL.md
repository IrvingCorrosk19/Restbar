# 02 — BUSINESS MODEL

**Pregunta:** ¿Cómo debe ganar dinero RestBar *y* hacer ganar dinero al restaurante?

---

# 1. Modelo de valor del cliente (restaurante)

RestBar solo justifica suscripción si el dueño percibe **tres retornos medibles**:

| Retorno | Mecanismo producto | Meta 24 meses |
|---------|-------------------|---------------|
| **Ganar más** | Rotación mesa, ticket (combos/HH/upsell), recompra loyalty | +8–15% ventas |
| **Ahorrar más** | Food cost, merma, fraude caja, horas admin | −2–4 pts food cost |
| **Controlar / decidir** | Command Center, alertas, forecast, copiloto | Decisiones sin Excel |

**Regla de producto:** Si un feature no mueve uno de estos tres, **no entra al roadmap core**.

---

# 2. Segmentos objetivo (orden de ataque)

| # | Segmento | Willingness to pay | Fit RestBar hoy | Fit post-transformación |
|---|----------|--------------------|-----------------|-------------------------|
| 1 | Full-service 1–5 locales LATAM | $80–150/local/mes | Piloto POS+KDS | **Core ICP** |
| 2 | Mini-cadenas 6–20 / multiempresa | $120–250/local | MT fuerte | **Growth** |
| 3 | Franquicias regionales | $150–300 + HQ | MT parcial | Año 2 |
| 4 | Dark / cloud kitchen | $100–200 | KDS sí | Año 2 |
| 5 | Hotel / casino / aeropuerto | Enterprise | **No** | Año 3+ |
| 6 | QSR global (McD/Starbucks) | N/A | **No** | No objetivo |

**No competir** primero con Oracle en hotel. **Sí competir** con Toast/Square mid-market en LATAM full-service + multi-sucursal.

---

# 3. Modelo de ingresos RestBar (SaaS)

| Plan | Incluye | Precio guía LATAM |
|------|---------|-------------------|
| **Starter** | POS + mesas + pagos básicos | $49/local |
| **Ops** | + KDS multi-estación + inventario estación | $99/local |
| **Business** | + Caja + precuenta + compras + food cost + reportes export | $149–179/local |
| **Chain** | + HQ multiempresa + dashboard ejecutivo + forecast | $199–249/local |
| **Franchise** | + packs franquicia + BI + Copilot | $299+/local + HQ fee |

Add-ons: Fiscal país, Delivery connectors, Labor, Loyalty.

**Gate comercial:** No vender Business/Chain hasta que caja+compras+export estén **reales** (hoy bloquea credibilidad).

---

# 4. Propuesta de valor vs POS puro

| POS tradicional | RestBar destino |
|-----------------|-----------------|
| Cobrar y imprimir | Generar margen y crecimiento |
| Reportes históricos | Decisiones + alertas + forecast |
| Un local | Multiempresa / franquicia nativa |
| Módulos sueltos | Plataforma de gestión (Ops + Money + Intelligence) |

**Tagline estratégico:**  
*"De la cocina al margen: la plataforma que opera, controla y decide por el restaurante."*

---

# 5. Unit economics (hipótesis)

| Métrica | Año 1 | Año 2 |
|---------|-------|-------|
| ARPU | $110 | $160 |
| Gross margin SaaS | 75% | 80% |
| CAC (piloto asistido) | $800–1,500 | $400 (self-serve) |
| Churn mensual | <4% | <2.5% |
| Payback CAC | 8–12 meses | 4–6 meses |

**Acelerador ROI RestBar (vendedor):** cerrar table stakes → subir plan Ops→Business → ARPU +40%.

---

# 6. Qué monetiza cada capa de producto

| Capa | Monetiza porque… |
|------|------------------|
| POS+KDS | Dolor diario visible |
| Caja+Fiscal | Obliga a pagar (compliance + control) |
| Compras+Food cost | CFO justifica presupuesto |
| Promos+Combos+Loyalty | Dueño ve ticket subir |
| Command Center+BI | Cadena/franquicia escala |
| Copilot IA | Diferenciación y upsell premium |

---

# 7. Anti-modelo (qué NO vender)

- “Suite enterprise completa” hoy → quema confianza  
- Módulos fantasma (Supplier 404, export vacío) → **ocultar hasta listos**  
- Precio Toast-parity sin paridad de capacidad  
- Vertical hotel/casino antes de mid-market LATAM sólido
