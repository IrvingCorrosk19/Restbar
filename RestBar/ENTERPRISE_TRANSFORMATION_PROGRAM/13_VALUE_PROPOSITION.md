# 13 — VALUE PROPOSITION

---

# 1. Propuesta central

## Para el dueño de restaurante / cadena regional LATAM

**RestBar** es la plataforma que une **operación de salón y cocina** con **control de costos y decisiones**, para que ganes más, gastes menos y sepas qué hacer cada día — sin necesitar un ejército de analistas ni pagar suite norteamericana.

---

# 2. Antes / Después

| Antes (Excel + POS débil) | Con RestBar transformado |
|---------------------------|--------------------------|
| Cocina caótica | KDS multi-estación certificado |
| Caja ciega | Arqueo y cierre Z |
| Food cost desconocido | Teórico vs real |
| Compras por WhatsApp | PO + recepción + stock |
| Ticket plano | Combos + HH + upsell |
| Reportes el domingo | Command Center <5s |
| Abrir sucursal = caos | Multiempresa nativo |
| “¿Qué hago hoy?” | Copilot con acciones |

---

# 3. Pilares de valor (mensajes)

1. **Opera** — POS + KDS que no pierden pedidos  
2. **Controla** — Caja, inventario, compras, food cost  
3. **Crece** — Promos, loyalty, multi-sucursal  
4. **Decide** — Command Center + BI + Copilot  

---

# 4. Prueba de valor (métricas piloto)

Todo piloto debe medir:

| KPI | Baseline → Target 90 días |
|-----|---------------------------|
| Ticket time cocina | −15% |
| Cash variance | <0.5% ventas |
| Food cost % | −1.5 a −3 pts |
| Ticket promedio | +5% (con combos/HH) |
| Horas admin reporte | −50% |
| Rotación mesa | +8% (con precuenta) |

Si no se mueve ≥2 KPIs, el producto no se vende como “plataforma de gestión”.
